# Code of conduct

ViewSense for CodeIgniter follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be welcoming and respectful, whatever someone's experience, background or identity.
- Give and accept constructive criticism. Focus on the code and the problem, not the person.
- Harassment, insults, personal attacks and sharing someone's private information are not
  accepted.

This applies to issues, pull requests, discussions and any other project space.

## Reporting

If someone's behavior makes you uncomfortable, contact the maintainer privately through
[their GitHub profile](https://github.com/Ezar101). Reports are handled confidentially. The
maintainer may edit or remove comments, and block people who break these rules, following the
enforcement guidelines of the Contributor Covenant.
